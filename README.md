# PMSM Motor-Control Test Bench Using TI F28379D

> Personal engineering project currently under development.

This project develops a PMSM motor-control test bench using the TI
LAUNCHXL-F28379D controller, BOOSTXL-DRV8305EVM inverter and a Teknic
M-2321G-QN-16D motor.

## Planned Features

- Three-phase PWM using ePWM1, ePWM2 and ePWM3
- Space Vector Pulse Width Modulation
- Potentiometer-based speed command
- Encoder-based rotor position and speed measurement
- Closed-loop speed control
- Fault detection and safe PWM shutdown
- RGB operating-status indication

## Development Status

The project is currently in the hardware bring-up and peripheral-validation stage.

## Hardware

- TI LAUNCHXL-F28379D
- BOOSTXL-DRV8305EVM
- Teknic M-2321G-QN-16D
- DC power supply
- 10 A protection fuse
- Potentiometer
- RGB status LED
- Oscilloscope
